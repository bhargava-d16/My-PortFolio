A full-stack job portal used by 50+ test users to browse, save, and apply for jobs with personalized profiles. Implemented secure authentication and authorization using **JWT** for sessions and profile protection. Integrated **Cloudinary** for optimized storage and retrieval of 100+ image and resume uploads, and built a real-time video interview feature using **Agora SDK** to eliminate third-party dependencies.
