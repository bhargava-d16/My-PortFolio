A smart URL shortener and link aggregator allowing users to group multiple URLs under a single smart link that opens them simultaneously. Integrates a real-time analytics dashboard tracking clicks, device types, and usage patterns. Leverages **Redis caching** to reduce primary database load by 40% for redirect routing, and is deployed on **AWS EC2** with **Nginx** for high reliability.
