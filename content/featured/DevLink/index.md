A real-time collaboration platform designed for teams of 5–10 users to live-code and message simultaneously. Features dynamic ZIP/GitHub project upload with automatic backend extraction to parse and generate code file trees. Managed editor state, active tabs, and tree structures with **Zustand** for real-time synchronization, and integrated **Socket.IO** for low-latency code editing and chat.
