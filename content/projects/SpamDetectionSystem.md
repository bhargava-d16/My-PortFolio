A real-time text classification application built to identify spam messages with high accuracy. It features an **LSTM-based Deep Learning** model trained with custom text preprocessing, tokenization, and padding pipelines. The model is deployed as a high-throughput **FastAPI** web service, capable of serving live predictions with confidence scores.
